# Protein-HTVS-Analyzer
面向 AI 功能蛋白药物设计的智能分析平台。集成 ProteinMPNN 序列生成、AlphaFold 3 结构验证 (RMSD) 与 Kyte-Doolittle 高通量理化筛查工作流。
## 核心痛点与解决方案
当前如 ProteinMPNN 等逆向折叠 AI 模型能生成大量序列，但往往忽略了序列在真实湿实验中的理化稳定性与结合界面重叠度。本系统作为 AI 序列生成后的**风控漏斗**，通过结构叠合与理化扫描，在湿实验前精准剔除脱靶与易聚沉的劣质序列，大幅降低研发成本。

## 核心功能模块

系统包含四大高度集成的分析看板：

### 1. 理化性质高通量扫描面板 (HTVS)
* **批量初筛漏斗：** 支持上传包含多条序列的 `.fasta` 文件，自动并行计算疏水氨基酸占比与 GRAVY 得分，一键标红淘汰聚沉风险（>45%疏水）的序列，并支持导出纯净版候选池。
* **精细显微镜：** 提供 Kyte-Doolittle 亲疏水性滑动窗口图谱，精准定位序列局部的潜在疏水跨膜区或易沉淀斑块。

### 2. 3D 结构高精度比对 (Structural Superimposition)
* **双模态输入：** 支持 `.pdb` 与 `.cif` 格式（兼容 AlphaFold 3 输出标准）。
* **定量与定性验证：** 基于 Cα 原子进行 Needleman-Wunsch 序列对齐与三维空间叠合，自动计算 RMSD（均方根误差），并提供实时的双结构差异对比 3D 渲染视图，确保 AI 生成序列未破坏核心承重骨架。

### 3. 多序列保守性分析 (Conservation Analysis)
* 自动解析 `.aln` 多序列比对文件。
* 绘制残基级别保守性热力图与分布曲线，精准识别不可轻易突变的关键功能锚点（高保守区）与极具改造潜力的柔性区域（低保守区）。

### 4. 基础 3D 结构可视化
* 搭载轻量化 Py3Dmol 引擎，支持多种视图模式（卡通、球棍、表面）的无缝切换与潜在药物口袋粗筛。

## 技术栈
* **前端框架:** Streamlit
* **生物信息学引擎:** Biopython (结构解析、RMSD计算、序列特征提取)
* **三维分子渲染:** py3Dmol
* **数据可视化:** Plotly & Pandas
